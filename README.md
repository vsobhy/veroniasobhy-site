# veroniasobhy.com

Personal site for Veronia Sobhy. Static site, no build step, no dependencies.

`index.html` is the artist-buddy homepage. `resume.html` is the same offer as a long page.
The previous builder-and-operator site is preserved at `dev/index.html` (`/dev`) and
`dev/resume.html` (`/dev/resume`).

## Deploy
Vercel, framework preset **Other**, no build command, output directory = repo root.

## Domains
- veroniasobhy.com (primary)
- veronicasobhy.com (redirects to primary, common typo)
